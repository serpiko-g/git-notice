Правила коммитов по Conventional Commits
Сообщение коммита строится по шаблону:

<тип>[область]: <краткое описание>


тип — указывает, что за изменение было сделано;
область (необязательно) — конкретная часть проекта (например, модуль или файл);
описание — кратко, что именно изменилось.
Основные типы коммитов:
feat - Добавлена новая функциональность
пример:
feat: добавлен подсчёт среднего числа
fix - Исправлена ошибка
пример:
fix: исправлено деление на ноль
docs - Изменения в документации
пример:
docs: добавлена инструкция по функционалу подсчета среднего числа
refactor - Изменения в коде без добавления нового функционала и без исправления багов
пример:
refactor: упрощена логика сортировки массива
